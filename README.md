# TTS Tester

Text-to-speech engine comparison and testing tool.

Built with GTK4/Adwaita. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install tts-tester
```

### Fedora/RPM
```bash
sudo dnf install tts-tester
```
